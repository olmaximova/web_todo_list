# web_todo_list
To-Do List | University Web Development Project 

# Описание 
Репозиторий содержит код для создания ToDo-листа.

# Функциональность
1. Пользователь может создавать, редактировать и удалять задачи, а также отмечать их как выполненные
2. Пользователь может фильтровать задачи, сортировать их по дате
3. Пользователь может искать задачи по названию, а также просматировать уже прошедшие задачи, задачи на сегодня и предстоящие задачи
4. Полльзователь может менять порядок задач с помощью drag-and-drop
5. Обеспечено сохранение задач в localStorage и восстановление при загрузке страницы

# Описание некоторых функций:
1. Сортировка по дате: чтобы отсортировать задачи по дате необходимо нажать на заголовок столбца с датами, то есть на слово "Date". После этого задачи отсортируются. Если необходимо отсортировать в обратном порядке - нужно нажать на заголовок еще раз. Если необходимо сбросить сортировку - перезагрузите страницу.
2. Чтобы отсортировать задачи по принципу "прошедшие-на сегодня-на следующие дни" необходимо выбрать соответвующую функцию в меню (в сайдбаре)
3. Drag-and-drop на мобильных устройствах может немного лагать. Необходимо некоторое время удерживать задачу, а затем переместить ее в нужное место. 
4. Для того чтобы отредактировать задачу необходимо нажать на значок ручки в разделе "Actions". Чтобы закончить редактирование - нажать на него еще раз. 

# Макет страницы
1. В HTML файле содержится только базовый каркас страницы
2. Файл main.js служит для создания таблицы с задачами, а файл sidebar.js для создания сайдбара (меню страницы)
3. Все элементы создаются через DOM API
4. Используются семантические теги

# Технологический стек
Для выполнения были использованы чистые HTML, CSS, JavaScript. Без использования фреймворков. Также с помомощью Google Fonts был добавлен шрифт Outfit.

# Адаптивность
ToDo-лист адаптирован под различные устройства и корректно отображается на ноутбуках, планшетах и телефонах.
